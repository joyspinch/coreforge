# 炉心边境 · COREFORGE

> Zan 原生 2D 工厂自动化 + 塔防：开采矿石、传送、加工、供电、抵御 20 波进攻并完成科技树。

用 [Zan](https://github.com/joyspinch/zan-lang) 语言写的独立游戏项目（仓库根自带 git 仓库）。完整设计与实现说明见 [`PROJECT.md`](PROJECT.md)。

## 玩法

采集（矿脉钻头/取水泵/油井）→ 传送（传送带/分流器/管道）→ 加工
（电弧熔炉/晶格装配机）→ 电力（热差发电机/蓄电池/电力中继）→ 防御
（脉冲炮塔/苍穹散射/穿云狙炮/崩地臼炮/棱镜聚焦塔/合金墙）→ 支援
（修复投影/过护投影/力场护盾）→ 波次进攻→ 反击（铁蜂机巢组装无人机）
→ 科技研究（15 项：热工学/晶格工程/弹道校准/物流增压/炉心扩张/
双管齐射/远程压制/攻城火力/纳米修复/铁蜂编队/棱镜聚焦/纳米投影/
过护力场/局能力场）→ 拔除敌巢、扩张新的远征据点。

防御纵深是核心课题：炮塔各有分工——脉冲均衡、散射双管速刷蜂群、
狙炮远程点名重甲、臼炮曲射溅射（无法对空）、棱镜持续光束灼蚀单体
（耗电极大）；敌军同样分层——3 波起混入重甲兽、5 波起混入自爆奔兽、
7 波起混入**飞行掠翼虫**（无视地形与建筑直线扑向炉心），没有对空火力
的防线会被撕开。研究纳米修复后全部建筑随时间缓慢自修。

### 支援三塔

防御不止火力。研究纳米投影系科技后解锁三座支援塔，全部依赖供电：

- **修复投影**：范围内全部建筑每刻持续修复（可叠加），防线无需人工照看；
- **过护投影**：范围内钻头与加工厂效率大幅提升（叠加取最大），被增益的
  建筑会亮起琥珀色双箭头标记；
- **力场护盾**：张开 3 格半径的力场泡，先于墙体吸收来犯啃咬与炮火；
  断电或耗尽后缓慢重张，盾值在选中详情与小地图气泡上可见。

### 难度与开局简报

点 **新远征 / 再来一局** 先进入远征简报幕：三档难度——平静（敌军 85%）、
标准（100%）、严酷（数量 120% · 强度 130%）——选定即出发。难度只缩放
波次数量与强度，随存档保存（v5）。准备期顶栏下方挂着**波次预告条**：
下一波的兵种构成、数量与倒计时一目了然（与出兵公式同源，预告即真相），
波次中自动隐去。

### 反击战：拔除敌巢

地图三侧各有一座**敌巢**——它是该通道的出兵口。研究铁蜂编队后建造
**铁蜂机巢**（消耗铜铅硅自动组装无人机，战损自动补充，上限 24 架）：
守卫模式下铁蜂拦截逼近炉心的来犯敌人；切到**进攻**模式（工具栏
按钮），铁蜂群会飞向最近的敌巢啃咬——巢穴会拍死靠近的无人机，拔巢
有战损代价。摧毁一座巢即拔除一条出兵口：该通道从此不再出兵，并获得
铜铅钛重赏；三巢全拔，敌军永绝，只剩清完剩余波次即可凯旋。研究棱镜
聚焦还可建造**棱镜聚焦塔**，用巨额电力换取单点持续灼蚀的终极火力。

### 蓝图复制 / 粘贴

按 **B**（或工具栏 蓝图 按钮）进入框选：按住左键框住成型的生产线或
防御群，松开即捕获（最多 256 座）；再按左键把整组建筑粘到新位置——
占位、越界或资源不足的格子自动跳过，其余照建，可连续粘贴多处；
**R** 顺时针旋转 90°（朝向同步旋转），**Q / Esc / 右键 / 再按 B** 收起。
蓝图是会话工具，不进存档。

### 无尽坚守

第 20 波清空即远征胜利。结算幕上的 **无尽坚守** 让远征继续：波次
不再读目录表，改为公式生成——每波敌人多 3 名、强度每波 +12%、
每 5 波一位首领、出兵间隔逐步压到底线。防线会持续被更强的波次考验，
直到炉心失守为止；无尽档与普通档同样可存可读。

- **鼠标左键**：放置/点选/蓝图框选与粘贴；**右键拖拽**：平移相机；**滚轮**：缩放；
- **WASD / 方向键**：移动相机；**R / Q / X**：旋转（蓝图态旋转图纸）/ 取消 / 拆除；
- **空格**：暂停；**T**：科技面板；**B**：蓝图；**1 / 2 / 3**：游戏速度 / 迎敌 / 回炉心；
- 顶栏/工具栏/目标/详情/科技/建造栏/状态栏/结算幕全部是 HTML+CSS
  声明式控件（`src/App.html` 设计稿 + `skins/coreforge/skin.css` 熔核
  皮肤），点击即用；小地图与边缘预警是画布上的游戏坐标热 HUD。

## 构建

需要 [zan-lang](https://github.com/joyspinch/zan-lang) 仓库（`zanc` 编译器、公共包与 stdlib 都在里面）：

```powershell
git clone https://github.com/joyspinch/zan-lang.git
$env:ZAN_HOME = 'D:/path/to/zan-lang'   # 指到刚克隆的 zan-lang 仓库根

pwsh -File client/tools/build.ps1
```

产物：`build/coreforge/Coreforge.exe`（运行目录要带上它旁边的 `assets/` 与 `skins/`）。

## 运行

```powershell
cd build/coreforge
.\Coreforge.exe
```

## 测试

```powershell
pwsh -File client/tools/test.ps1
```
